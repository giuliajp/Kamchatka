# Интерфейс «Авачи»

Эталон: Figma `dZcOxRfG88AY1tWW1s7HKH`, страница `339:7522` «Для разработки».
Карта — `339:7524`, будущий этап — `339:7837`, завершённый — `352:7421`.
Приоритет обновлённой группы участника `462:11182`, компактный кадр `462:10977`;
легенда — группа `462:10123`. Новые экраны Wireframes в эту поставку не входят.

Структура и стили прочитаны через Computer Use в настольной Figma. Повторная
визуальная сверка обновлённой карточки выполнялась также в браузерной Figma:
настольное окно перестало надёжно обновлять изображение после действий.

Эталон — 360 × 800. Поля 16 px; обычный маркер 36 px, поддерживаемый — 44 px,
кластер 28 px, кнопки карты — 44 px; нижняя навигация — 48 px плюс safe area.
Компактная шторка занимает 80dvh, развёрнутая — 92dvh. Верхние теги выступают
над скруглением, аватар — 72 px; имя 20/24, основной текст 13/16, показатели 14/18.
Легенда располагается над нижним меню, а крупный текст прокручивается внутри неё.

Локальные Gotham Pro (400/500/700/900) и VK Sans Display подключены в fonts.css.
Семейства, начертания и кириллица проверены по таблицам шрифтов. Происхождение
файлов и ещё не подтверждённые права на web-распространение записаны в
`frontend/public/fonts/SOURCES.md`. Установлены также desktop-файлы для Figma.
До подтверждения этих прав типографическая приёмка для публичной поставки открыта.

Кольца, часы, корона, кластер, обложка, логотип и медиа используют локальные
исходные ассеты. Полные изображения экранов не используются как интерфейс.
Реальные имена, даты, фотографии, география и число КП приходят из API и меняют
наполнение. Неподключённые медиа и отметки КП явно обозначены демонстрационными.

GPS-место не выдаётся за официальное; километры не превращаются в отставание
по времени. На рабочей карте используются только подтверждённые точки API.
Расчётное положение показано исключительно в справочной легенде и UI-kit.
Нижнее меню содержит пять пунктов; два пока открывают информационное сообщение.

На широком экране карта ограничена 768 px, экраны неидущих этапов — 480 px.
У таблиц собственная горизонтальная прокрутка. Крупный текст переносится;
геометрия маркеров и аватаров сохраняется. Reduced motion отключает переходы.
Тёмная тема использует функциональные токены VKUI; визуальный эталон — светлая.

Отличия от статического макета с объяснимой причиной: подложка OpenStreetMap
через Leaflet и атрибуция поставщика; реальные показатели API;
подписи источников демонстрационных данных;
отсутствующий VK host chrome у самостоятельного браузерного запуска; карта
опубликованного маршрута вместо иллюстрации вымышленной географии. Нельзя
считать эти экраны попиксельной копией фиксированного контента Figma.
