# Проверки обновления дизайна — 4 ноября 2026

Все браузерные данные синтетические, API работает с отдельным PostgreSQL 16.
Реальный production и доставка VK не затрагивались.

| Проверка | Результат |
|---|---|
| Frontend `npm run check` | 296 тестов, по 100% statements/branches/functions/lines каждого файла; lint, TS, production, Storybook прошли |
| Admin `npm run check` | 105 тестов, тот же порог 100%; lint, TS, production, Storybook прошли |
| Backend pytest, UTF-8 | 289 passed |
| Настоящий HTTP API | 62 проверки: CRUD/публикация контента, новые типы, /me, напоминания, настройки, PDF-закладки, удаление места |
| Миграции | Заполненная 0007 → head, сохранение контента, CHECK новых типов, защищённый откат, повторный upgrade, alembic check |
| 360/390/768/1280, light/dark | Внешнее горизонтальное переполнение отсутствует в «Ещё» и результатах; программа и шторки дополнительно проверены на мобильном/планшете |
| Текст 200% | 360 px профиль и 768 px админка: поля и переключатели доступны, страница не расширяется |
| Клавиатура шторки | Tab остаётся внутри; Escape закрывает карточку и возвращает исходный URL |
| Жест | Настоящее перетаскивание верхней ручки через Pointer Events закрывает шторку; используется pointer capture |
| Возврат | Событие → место → событие → день; результат → карточка → трек → карточка; hash/deep links проверены тестами |
| Админская сессия | После истечения и входа тем же тестовым организатором введённое название сохранено |
| Медленная загрузка справочников | Существующий этап и место восстанавливаются; сохранение до загрузки не отвязывает материал |
| Консоль мини-приложения | Ошибок нет; остаётся предупреждение VKUI о deprecated Div существующего UI-kit |
| Размер сборок | Оба сборщика предупреждают о JS-чанках больше 500 kB; сборка успешна |
