# UI-kit: первый перенос состава на VKUI, 16.10.2026

> Исторический отчёт. Актуальное разделение и сверка: [UI_KIT_FIGMA_AUDIT.md](UI_KIT_FIGMA_AUDIT.md). Общая story впоследствии удалена, шрифты включены в аудит.

## Согласованные границы

Источник: [UI kit, Для разработки](https://www.figma.com/design/leyJ5DGOJdTNJlQHtgJTnJ/?node-id=339-7869).
После Select пользователь поручил перенести все оставшиеся компоненты и явно
выбрал: **весь состав и поведение на стандартных токенах VKUI; точная визуальная
сверка позже**. Шрифты также отложены. Остановка после каждого компонента для
этого прохода больше не требуется.

Это функциональный перенос состава, не подтверждение пиксельного совпадения.
Figma MCP возвращает Unknown tool; нативный просмотр показывает весь UI-kit,
но клики по слоям не меняют выбор. Размеры остальных слоёв не выдумывались.
Использованы VKUI 8.4.2 и @vkontakte/icons 3.76.0; зависимости не обновлялись.

## TDD и проверки

Для каждого из 15 новых рабочих компонентов сначала создан тест, подтверждён
RED на отсутствии модуля, затем реализация до GREEN. Логи этапа:
`/tmp/avacha-{banner,tabs,tabbar,stage-row,time,leaders,marker,route,preferences,prompt,event,position,sheet,header,controls}-{red,green}.log`.
Отдельный цикл проверил повторный выбор уже выбранной дисциплины при вкладке
«Мои»: RED → возврат к «Все» и закрытие меню → GREEN.

После браузерного аудита добавлены регрессионные проверки доступных названий
маркера/события и отсутствия одиночных listitem. Подтверждён RED, исправлена
семантика Card и названия кнопок; GREEN. `/tmp/avacha-a11y-{red,green}.log`.
VKUI не подменялся. В jsdom предоставлены только отсутствующие браузерные API:
matchMedia, ResizeObserver и scrollTo.

Финальный `npm run check` проходит:

- 75 тестов в 24 файлах;
- 26 рабочих файлов, каждый **100/100/100/100**;
- statements 85/85, branches 79/79, functions 50/50, lines 79/79;
- lint, typecheck, сборки приложения и Storybook.

Чистая установка lockfile отдельно проверена в новом временном каталоге:
`npm ci --no-audit --no-fund`, 340 пакетов, код завершения 0.
Лог установки: `/tmp/avacha-clean-install.log`.

Лог проверок: `/tmp/avacha-all-kit-final-check.log`. Coverage include/exclude и пороги
не менялись. Отчёты: `frontend/coverage/index.html`, `frontend/coverage/lcov.info`,
текстовый вывод. CSS проверяется браузером, не V8. Сборка Storybook предупреждает
о размере чанков; сборка успешна.

В браузере проверены выбор дисциплины, поддержка, открытие/закрытие подписки и
карточки участника; обе темы; отсутствие горизонтального переполнения общего
каталога на 360/390/768/1280 px. Проверен масштаб Storybook 200% (масштаб всего
canvas, не увеличение только текста). Нативные рамки button убраны у композиций
Banner/SimpleCell/Tappable; сохранены стили и фокус VKUI.

## Отложенная визуальная сверка

Accessibility общего каталога после исправления семантики показывает только
color-contrast: 33 элемента в светлой теме, 12 в тёмной; 31 пройденное правило
и 3 inconclusive. Это не финальная приёмка доступности. Правила axe не отключались,
палитра не изменялась ради отчёта.

Следующий проход: семьи шрифтов по конкретным слоям, точные размеры/отступы,
цвета и варианты иконок, капсула меню/закрытия, форма маркеров и легенды, вид
меню, исходные изображения, отдельная проверка увеличения только текста до
200%, окончательный контраст. Это не часть завершённого переноса на стандартных токенах.
