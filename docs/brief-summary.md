# Бриф — краткая выжимка

Полный бриф — у продюсера/партнёра проекта (файл `Бриф_VK_Mini_App.docx`). Здесь только суть, чтобы
команде не искать её в 10-страничном документе.

## Кто заказчик

Министерство туризма Камчатского края. Продукт — мини-приложение ВКонтакте (VK Mini Apps) для гонки
«Авача» в рамках зимнего фестиваля «Берингия».

## Что за продукт

«Авача» — самая сложная в России гонка по ездовому спорту (~300 км, перевалы, природный парк
«Налычево»). Приложение — единый цифровой хаб события:

- болельщик из любой точки следит за гонкой в реальном времени;
- гость Камчатки находит всё для поездки и посещения.

## Ключевая особенность (и сложность)

Трасса труднодоступна, увидеть её вживую почти нельзя — приложение показывает то, что иначе не видно.

Данные о позиции участников приходят от спутниковых трекеров **раз в ~20 минут** (не непрерывно!).
Это определяет всю логику карты и статусов "актуально / не актуально" — см. раздел
«Данные трекинга» в полном брифе, это одна из самых важных технических деталей проекта.

## Аудитория

- Действующая: участники, каюры, зрители на месте, жители Камчатки.
- Целевая для роста: онлайн-болельщики по всей России, молодёжь 18–35 (ВКонтакте), туристы,
  планирующие поездку, медиа/партнёры/спонсоры.

## Основные функции (MVP)

1. Карта с позициями участников + время последнего обновления.
2. Маршрут: трасса, КП, профиль высот.
3. Карточка участника (фото, дисциплина, позиция, скорость, отрыв).
4. «Болею за» + push-уведомления по конкретному участнику + счётчик болельщиков.
5. Результаты: сводная таблица, протоколы по этапам, штрафы.
6. Программа фестиваля + карта зрительских локаций.
7. Новости, трансляции (VK Видео), фотогалерея.
8. Раздел «Гостям»: как добраться, что взять, FAQ.
9. Авторизация VK ID, шеринг в историю/на стену, push, избранное.
10. Админ-панель для организаторов (участники, этапы, результаты, контент, push, мониторинг трекеров).

Полный список экранов — в `docs/screens.md`.

## Важные ограничения дизайна и логики

- **Mobile-first**, карта — главный экран.
- Крупные элементы, высокий контраст — приложение должно читаться на морозе и на солнце.
- Светлая и тёмная темы — обязательны.
- Приложение обязано корректно работать офлайн / при потере соединения: показывать последние
  загруженные данные и время обновления, баннер "Нет соединения", не показывать пустой экран.
- Положение участника — это **последняя подтверждённая точка** с подписью времени, а не "живое"
  движение. Скорость — средняя между двумя точками, а не мгновенная.
- Официальное время прохождения КП — только по отметкам судей, не по трекеру.
- SOS-сигнал с трекеров виден **только** в админ-панели, никогда в публичной части приложения.

## Референсы

Iditarod Insider / Iditarod GPS Tracker, Trackleaders.com, Yukon Quest — эталон подачи live-трекинга.
