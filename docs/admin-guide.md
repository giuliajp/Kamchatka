# Инструкция для администратора и контент-менеджера

Административная панель «Авачи» — всё, что видят болельщики в мини-приложении, меняется здесь,
без разработчика и без выпуска новой версии.

**Время** во всех полях — камчатское (UTC+12).
**Черновик и публикация:** новые материалы и протоколы сначала не видны болельщикам.
Они появляются в приложении после галочки «Опубликовано в приложении» или кнопки «Опубликовать».

## Вход

Откройте адрес админки, введите логин и пароль. Вход действует 12 часов, потом нужно войти заново.
Учётные записи создаёт администратор сервера (см. `backend/README.md`, раздел «Организаторы админки»).
У каждого сотрудника — свой логин: имя попадает в журналы правок.

## Перед сезоном

### 1. Сезон
**Этапы и маршрут → вкладка «Сезон» → «Создать сезон».**
Название (как увидят болельщики, например «Берингия. Авача 2027»), год, даты, место.
Затем выберите новый сезон в списке вверху слева, поставьте галочку
**«Текущий сезон в приложении»** и сохраните — приложение будет показывать его по умолчанию.
**Статус сезона** переключает режим приложения: «Ожидается» — до гонки, «Идёт», «Завершён».

### 2. Дисциплины
**Этапы и маршрут → «Дисциплины».** Справочник уже заполнен (лыжи, нарта 8 собак, нарта более 8).
Новую дисциплину добавляйте только по решению судейской коллегии. Код не меняется после создания.

### 3. Этапы
**Этапы и маршрут → «Этапы» → «Новый этап».** Номер, название, длина, старт и финиш.
Интервал и просрочку GPS можно не заполнять — возьмутся из настроек сезона (20 и 45 минут).

**Маршрут этапа:** выберите этап → блок «Маршрут» → файл GPX, KML или KMZ → «Загрузить маршрут».
Маршрут можно заменить и во время гонки. Профиль высот строится автоматически, если в файле
есть высоты: файлы из Google «Мои карты» выгружаются без высот — сохраняйте трек из Google Earth
или GPS-редактора.

### 4. Контрольные пункты
**Этапы и маршрут → «Контрольные пункты».**
Сначала **«Новое место»** — название и координаты. Затем выберите этап → **«Добавить КП»**:
порядковый номер (0 — старт), роль (старт, КП, финиш), обозначение («КП-2»), километр от старта,
обязательный отдых и описание участка до этого КП (показывается на экране «Маршрут»).
КП, на котором уже есть отметки судей, удалить нельзя.

### 5. Участники
**Участники → «Новая заявка».** Если спортсмен выступал раньше — найдите его в «Спортсменах прошлых
лет», иначе введите ФИО и год рождения. Стартовый номер, дисциплина, регион, число собак, порода.
**Карточка спортсмена:** ссылка на фотографию, биография, **ID страницы VK** — по нему приложение
показывает спортсмену «Мой результат».
Участника с результатами, отметками или GPS-точками удалить нельзя — ставьте статус DNS или DNF.

### 6. Трекеры
**Мониторинг оборудования → «Трекеры».** Трекеры Iridium появляются сами (выключенными).
Выберите трекер → **«Выдать трекер»** участнику, при необходимости — на конкретный этап.
Прошлая выдача закрывается автоматически. «Принимать точки с трекера» включается при выдаче.

### 7. Контент
**Контент**, вкладки:
- **Программа** — события по дням: тип (старт, финиш, культурная программа, мастер-класс, встреча),
  время, место, описание, ссылки на фото.
- **Локации** — зрительские места с координатами, адресом и описанием, как добраться.
- **Гостям** — «Как добраться», «Что взять с собой», «Техника безопасности».
- **FAQ** и **Контакты**.

## Во время гонки

### Старт этапа
**Этапы и маршрут → этап → статус «Идёт».** Всем, кто разрешил уведомления, уйдёт push
«Этап N стартовал в ЧЧ:ММ по Камчатке».

### Мониторинг трекеров
**Мониторинг оборудования → «Мониторинг этапа».** Сначала — участники с SOS, затем просроченные.
**Просрочка** — нет точек дольше порога этапа (по умолчанию 45 минут). Это состояние устройства,
статус каюра не меняется. **«Запросить данные трекеров»** — опросить Iridium, не дожидаясь расписания.

### Отметки судей на КП
Официальное время — только отметки судей, трекер для этого не используется.
В мониторинге выберите участника → **«Быстрый ввод отметки»**: КП, время прибытия и отправления,
примечание. Болельщики участника получат push «КП-2 пройден в ЧЧ:ММ (отметка судьи)».
Каждая правка сохраняется в истории: кто, когда, что было и что стало.

### SOS
Сигнал тревоги виден **только в админке** и никогда — болельщикам.
Закрыть сигнал можно только с причиной: **«Урегулировать SOS»** → причина → «Подтвердить решение».
История — во вкладке «Журнал SOS».

### Протоколы этапа
Подробно — в [csv-import.md](csv-import.md). Коротко:
1. Судьи сохраняют лист Excel как CSV.
2. **Результаты → «Импорт CSV»** → файл → **«Проверить»**. Если есть ошибки — список строк;
   исправить в Excel и проверить снова. При ошибке не сохраняется ничего.
3. **«Загрузить»** — протоколы создаются черновиками.
4. **«Протоколы»** → проверить → **«Опубликовать»**. Болельщики увидят протокол и получат push.
5. После решения главного судьи — **«Утвердить»**. Утверждённый протокол меняется только через
   **«Исправить окончательный результат»** с основанием и именем утвердившего; в приложении у строки
   появится пометка об исправлении.

Можно поправить строку вручную или добавить результат — до утверждения, с причиной для журнала.

### Штрафы
**Результаты → «Штрафы».** Штраф относится к гонке, а не к этапу: штрафное время, пункт правил,
нарушение. Обычно штрафы приходят из примечаний протокола судей при импорте.

### Push-рассылки
**Push-рассылки → «Новое сообщение»**: текст до 254 символов, кому (всем или болельщикам участника),
какой раздел открыть. Пишите о том, что уже произошло, с временем — не «прямо сейчас».
В **журнале рассылок** видно, сколько получателей и сколько доставлено.

Автоматически push уходят при старте этапа, отметке на КП, публикации протокола, смене лидера
и по «колокольчику» у события программы (за 30 минут). Пользователь сам выбирает в профиле,
какие уведомления получать.

## После гонки

- **Этапы и маршрут → «Сезон»:** статус «Завершён», ссылка на PDF протокола гонки.
  Ссылку на PDF протокола каждого этапа — в настройках этапа.
- **Статистика болельщиков:** рейтинг и выгрузка динамики по дням в CSV для Excel.
- В следующем сезоне создайте новый сезон и сделайте его текущим — прошлые годы останутся в архиве.

## Что настраивается не в админке

- **Ключ VK и id сообщества** (push, новости, фото) и **ключ Iridium360** — вносит администратор
  сервера в файл `backend/.env`, затем перезапускает сервер.
- **Аналитика посещаемости** — встроенная статистика VK Mini Apps в кабинете разработчика
  мини-приложения.
- **Новости и фото** публикуются в сообществе ВКонтакте — приложение показывает их само.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| Просит войти заново | Прошло 12 часов — войдите ещё раз |
| Файл протокола не загружается | Прочитайте список ошибок: в нём номер строки и причина |
| «Этап N не создан» при импорте | Создайте этап в «Этапы и маршрут» |
| Участник не на карте | Проверьте, что трекер выдан ему и этап в статусе «Идёт» |
| Push «не доставлено» | Пользователь запретил уведомления или не задан ключ VK |
| Новостей и фото нет в приложении | Не задан ключ VK или id сообщества |
