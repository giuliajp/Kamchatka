## Реализация и TDD

`frontend/src/components/RaceStageSelect.tsx` использует настоящий CustomSelect
из VKUI. Контракт: `value`, `options`, `onChange(value)`, `disabled?`.
Опция содержит `value`, `label`, `details` и метаданные `upcoming?`.
Даты и описания приходят готовыми строками; времени и статуса компонент не вычисляет.
`upcoming` пока не влияет на оформление; цвет будущего этапа ещё предстоит перенести.

Сначала создан `frontend/tests/RaceStageSelect.test.tsx`. Первый RED завершился
ошибкой отсутствующего модуля. После минимальной реализации прошли три теста:
открытие/Escape, выбор будущего этапа с управляемым значением, клавиатура/фокус.
Затем добавлен тест disabled: подтверждён отдельный RED на toBeDisabled,
после передачи disabled в VKUI все четыре теста прошли. Заглушек VKUI нет.

Обновлён существующий раздел `Поля/SearchAndSelect`:
«Выбор этапа», «Раскрытый список этапов», «Будущий этап доступен для выбора»,
«Выбор недоступен». Истории поиска сохранены. Данные восьми этапов локальные.
Эталонная story использует светлый Android, viewport 360 px, ширину поля 328 px
и density regular в соответствии с Size Class в Figma. Перенос помечен рабочим.
