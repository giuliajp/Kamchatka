# Показ приложения заказчику (демо-сезон)

Демо-сезон «Гонка Авача 2027» заполняет все экраны как в макетах: идущий этап с участниками
на карте, завершённые этапы с протоколами, обратный отсчёт до следующего этапа, болельщики,
программа, «Гостям», мониторинг с SOS и просроченным трекером в админке.
Даты считаются от момента запуска: этап 3 всегда «идёт сейчас».

## Подготовка (один раз)

1. В `backend/.env` добавьте:
   ```
   VK_DEV_USER_ID=1
   DEMO_MEDIA=true
   ```
   Первая строка включает «Болею за» вне ВКонтакте, вторая — демонстрационные новости и фото.
2. Перезапустите бэкенд.

## Архив прошлого сезона (один раз)

Чтобы во вкладке «Архив прошлых лет» был протокол 2026 года:
```
python backend/scripts/parse_protocol.py --pdf docs/Total_result_Avacha-2026.pdf --output backend/scripts/demo_media/avacha2026.json
python backend/scripts/import_protocol.py --json backend/scripts/demo_media/avacha2026.json
python backend/scripts/publish_protocols.py --year 2026
```
Если сезон 2026 уже загружен — пропустите.

## Создать демо-сезон

Из корня проекта, с включённым окружением:
```
python backend/scripts/demo_season.py
```
Сезон станет текущим. Обновите мини-приложение и админку.

Перед показом лучше запустить скрипт заново — даты пересчитаются от текущего момента.

## Во время показа участники двигаются

В отдельном терминале:
```
python backend/scripts/demo_season.py --live
```
Каждую минуту у участников идущего этапа появляется новая точка. Остановить — Ctrl+C.

## Что показать

| Экран | Что видно |
|---|---|
| Карта | Этап 3 идёт: участники, «Положение на ЧЧ:ММ», топ-3 по GPS, ожидаемое время прибытия лидеров |
| Выбор этапа | Этапы 1–2 завершены (маршрут и итоги), этап 4 — обратный отсчёт |
| Участники | Сортировка по позиции, номеру, болельщикам; «+N за сутки» |
| Карточка | Фото, биография, порода, КП и обязательные остановки, штраф (№1), «Болею за» |
| Результаты | Протоколы этапов 1–2 по дисциплинам, DNF (№11) |
| Программа | События по дням, категории, фото, локации, колокольчик |
| Ещё | «Гостям», FAQ, контакты, «За кого болею», переключатели push |
| Админка → Мониторинг | SOS (№7), просроченный трекер (№9), отметки судей на КП |

## Убрать после показа

```
python backend/scripts/demo_season.py --remove
```
В `backend/.env` верните `DEMO_MEDIA=false` (или удалите строку).

На рабочем сервере заказчика (`ENVIRONMENT=production`) скрипт и демо-новости не работают.
Картинки демо-сезона лежат в `backend/scripts/demo_media/` и отдаются бэкендом только вне production.
