# Экраны приложения

Навигация: нижнее меню из 5 разделов — **Карта / Участники / Результаты / Программа / Ещё**

Каждому экрану ниже соответствует папка в `frontend/src/screens/`.

| № | Экран | Папка компонента | Коротко |
| --- | --- | --- | --- |
| 1 | Приветствие (первый запуск) | `Onboarding` | Показывается один раз, запрос push-разрешения |
| 2 | Карта (главный экран) | `Map` | Трек трассы, КП, метки участников, фильтры, топ-3 |
| 3 | Карточка участника | `ParticipantCard` | Фото, показатели, «Болею за», шеринг |
| 4 | Участники | `Participants` | Список, поиск, сортировка по позиции/болельщикам |
| 5 | Результаты | `Results` | Сводная таблица, протоколы по этапам |
| 6 | Маршрут | `Route` | Схема этапов, километраж, профиль высот |
| 7 | Программа | `Program` | Расписание по дням + карта зрительских локаций |
| 8 | Новости и трансляции | `News` | Лента, видео, фотогалерея по дням |
| 9 | Гостям | `Guests` | Как добраться, что взять, FAQ, контакты |
| 10 | Профиль | `Profile` | За кого болею, настройки push, сохранённое |

## Служебные состояния (не отдельные экраны, а состояния карты/данных)

- «Нет соединения» — последние загруженные данные + баннер.
- «Гонка ещё не началась» — обратный отсчёт, программа, туристический раздел.
- «Гонка завершена» — итоги, фотоотчёт, анонс следующего сезона.

## Админ-панель (`admin-panel/`)

Отдельный веб-интерфейс для организаторов, будущие страницы в `admin-panel` (исходников пока нет):

| Раздел | Что делает |
| --- | --- |
| Участники | Добавление/редактирование карточек, фото, статусы |
| Гонка | Этапы, КП, старт/финиш, ручной ввод судейских отметок |
| Результаты | Ввод и публикация протоколов, штрафы, остановки |
| Контент | Новости, расписание, локации, тексты, фотогалерея |
| Push-рассылки | Отправка по сегментам |
| Статус гонки | Переключение «до гонки» / «идёт» / «завершена» |
| Статистика болельщиков | Число подписчиков по участникам, динамика, выгрузка |
| Мониторинг оборудования | Статус трекеров, время последнего сигнала, SOS (только здесь!) |
