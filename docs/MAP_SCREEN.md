# Карта «Авача»: интерактивная демонстрация

Реализован раздел Figma `339:7523` в существующем frontend, без изменений backend.
Приложение открывает карту; компоненты и 16 сценариев экрана доступны в Storybook
в разделе **Экраны / Карта Авача**.

## Запуск

Из `frontend`: `npm run dev` и отдельно `npm run storybook`.
Приложение: http://127.0.0.1:5173/; Storybook: http://127.0.0.1:6006/.
В приложении используется системная светлая/тёмная тема; в Storybook — переключатель темы.

## Поведение

- Карта: перемещение мышью/касанием и стрелками при фокусе, масштаб 1–2,
  выбор дисциплины, её топ-3, лидеры каждой дисциплины, «Мои», кластеры и КП.
- Участник: шторка VKUI, раскрытие биографии, показатели, история КП, поддержка,
  закрытие фоном, Escape, кнопкой и штатным жестом ModalPage.
- Поддержка сохраняется в `avacha-map-demo-v1` в localStorage. Первый выбор открывает
  диалог уведомлений; его текст явно сообщает, что push не подключены.
  Если хранилище недоступно, выбор работает в памяти с пояснением.
- Этапы 1–2 завершены, этап 3 идёт, этап 4 запланирован. Таймер считает время от
  фиксированной точки демонстрации 09.02.2027 14:36 по Камчатке; ноль не переключает
  статус этапа автоматически. Часовой пояс подписан в меню экрана.
- Отчёт: исходная обложка, превью видео, просмотр фото и раскрываемая галерея,
  маршрут. Порядок 25 миниатюр, включая повторы, перенесён из Figma `352:7610`.
- Ошибки, загрузка, отсутствие координат, устаревшие позиции и offline доступны
  отдельными stories. События online/offline браузера обновляют предупреждение,
  сохраняя показанные позиции. «Обновить» восстанавливает только демонабор.
- Результаты, остальные разделы, видео и функции VK объясняют свою недоступность;
  новых продуктовых экранов и фиктивных сетевых запросов нет.

## Код и данные

Экран находится в `frontend/src/screens/Map`: `MapScreen`, `MapCanvas`, `StageContent`,
единый `demo.ts` и обычный CSS. Состояние — React, никаких новых зависимостей.
Расширены существующие композиции шапки, лидеров, баннера, шторки и диалога уведомлений.
Старые истории компонентов сохраняют прежние props; новые свойства необязательны.
AppProviders.fullScreen отключает трансформацию embedded AppRoot штатным свойством
VKUI, чтобы меню и сообщения закреплялись относительно viewport. Старые истории
по умолчанию сохраняют embedded-поведение.

Фикстуры следуют идентификаторам и статусам моделей backend, но **не являются
контрактом API**. XY карты — координаты демонстрационной сцены, не географические.
Места заданы отдельно внутри дисциплин; GPS не определяет официальные результаты.
Метки не движутся непрерывно. Сеть и свежесть координаты независимы. SOS отсутствует.
Backend проверен в `main` и `feature/parser-protocol` (`9330059`): модели и `/health`
есть, API карты и импорт результатов в БД не подключены. Backend не менялся.
