## Ограничения поставки

- Права на web-распространение копий шрифтов остаются неподтверждёнными:
  `frontend/public/fonts/SOURCES.md`. Перед публичным релизом нужны подтверждение
  либо лицензированные оригиналы. Техническая готовность PR не заменяет эту приёмку.
- Поддержка, подписки, отметки КП и медиа остаются явно подписанными локальными
  демонстрациями. Доставка push, VK host и живой Iridium не проверялись.
- В настоящем архиве нет маршрутов, GPS и точных стартов. Эти данные не выдумываются;
  географические live-сценарии проверены на фикстурах.
- CSS для prefers-reduced-motion проверен по исходникам. В доступном браузере нет
  управления этим media feature; фактическое включение настройки ОС не проверялось.
- Сохраняется предупреждение о размере JS-чанков приложения и Storybook. Сборки
  успешны; измерения скорости на слабом телефоне не проводились. Транзитивные
  overrides можно убрать после обновления потребляющих пакетов на исправленные версии.
- localStorage остаётся локальной демонстрационной моделью: общего серверного
  счётчика и транзакций между одновременно пишущими вкладками нет.
