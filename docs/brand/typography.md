# Типографика

Шрифт бренда — **Gotham Pro**, начертания: Light, Regular, Medium, Bold, Black.

Поддерживает кириллицу и латиницу.

## Что нужно сделать команде

1. Запросить у заказчика/дизайнера лицензионные файлы шрифта Gotham Pro (в брендбуке — только
   спецификация, не сами файлы). Класть их в `frontend/src/assets/fonts/`.
2. Если лицензии на Gotham Pro нет или её сложно получить вовремя — согласовать с заказчиком
   близкий open-source аналог (например, геометрический гротеск вроде Golos Text/Inter/Manrope)
   как временную замену для разработки, и явно пометить это в PR.
3. После согласования подключить шрифт в общей теме VKUI. Сейчас UI-kit использует
   стандартную типографику VKUI. Исходные значения сохранены в `docs/brand/theme.reference.ts`;
   Gotham Pro к приложению не подключён.

## Рекомендации по начертаниям (по аналогии с брендбуком)

| Начертание | Где использовать |
| --- | --- |
| Black / Bold | Заголовки экранов, названия участников, крупные цифры (позиция, скорость) |
| Medium | Подзаголовки, кнопки, навигация |
| Regular | Основной текст |
| Light | Вспомогательный/второстепенный текст, подписи |
