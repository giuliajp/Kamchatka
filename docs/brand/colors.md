# Цвета

Взято из официального брендбука проекта (`../design/brandbook/kamchatka-brandbook.pdf`,
тот самый, что указан по ссылке в брифе заказчика).

HEX ниже — приблизительный перевод из CMYK/Pantone брендбука (конвертация не идеально точная,
для финальной печатной продукции ориентируйтесь на Pantone/CMYK-значения, не на HEX).

## Логотип

- Кириллица и латиница, основная и инверсная версия.
- Обязательное охранное поле вокруг логотипа (x = высота буквы «М»), внутрь не должны попадать
  посторонние элементы.
- Недопустимо: менять цвет логотипа на произвольный, размещать на пёстром паттерне без плашки,
  ставить на низкоконтрастный фон.
- Файлы логотипа положите в `design/brand-assets/logo/` при получении векторных исходников от
  заказчика (в брендбуке логотип только растровый/в составе макетов).
