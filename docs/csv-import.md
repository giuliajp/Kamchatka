# Загрузка протокола из Excel судей (CSV)

Судьи ведут протокол в Excel. Вводить результаты руками в админке не нужно.

## Как сохранить файл

В Excel: **Файл → Сохранить как → CSV (разделители — точки с запятой)**.
Подходят кодировки UTF-8 и Windows-1251 (обычное сохранение русского Excel).
Если в книге несколько листов, сохраняется текущий — откройте лист с протоколом.

## Какой лист подходит

Тот же, из которого печатается итоговый протокол (как в 2026 году):

- строка «Дисциплина … Нарта-длинная дистанция 8 собак» перед каждым блоком;
- шапка с колонками «Стартовый номер», «ФИО», «Год рождения», «Субъект РФ»,
  «Этап 1 длина 33,7 км», «Этап 2 …», «Место», «Примечания»;
- вторая строка шапки («Результат», «Скорость») и колонки скорости, средней скорости,
  общего результата пропускаются — их можно не удалять;
- ошибки формул `#ЗНАЧ!`, `#ДЕЛ/0!` у сошедших — тоже.

Можно и одной таблицей без блоков: тогда в каждой строке колонка «Дисциплина».

**Необязательные колонки:** «Собак на старте 1», «Собак на финише 1» (номер — этап);
«Штраф» (ЧЧ:ММ:СС) и «Пункт» — вместо штрафа в «Примечаниях».

**Что пишется в ячейке этапа:** время ЧЧ:ММ:СС (часы могут быть больше 24), DNF, DNS, DSQ
или пусто — этап ещё не прошёл. Пустая ячейка ничего не меняет и ничего не удаляет.

**Штраф в «Примечаниях»:** как в 2026 году — «штр.вр. 2 мин. п.П.14.11.14».
Штраф относится к гонке, не к этапу.

## Порядок после каждого этапа

1. Админка → гонка → **Загрузить протокол** → выбрать файл → **Проверить**
   (`dry_run=true`). Ничего не сохраняется, видно, сколько строк добавится и изменится.
2. Если есть ошибки — список с номерами строк. Исправить в Excel, сохранить ещё раз.
   При ошибке не сохраняется ничего, даже правильные строки.
3. **Загрузить**. Протоколы этапа создаются черновиками: в приложении их пока не видно.
4. Проверить протоколы в админке → **Опубликовать**. Болельщики получат push.
5. После решения главного судьи → **Утвердить**.

Загружать можно весь файл целиком после каждого этапа: строки, которые не изменились,
не трогаются. Изменения в уже опубликованных протоколах сразу видны в приложении
и записываются в журнал правок с основанием «Импорт <имя файла>».

## Что проверяется

- Участника ищем по стартовому номеру. Если номера ещё нет — участник создаётся
  (нужны «Фамилия Имя [Отчество]»). Если под номером в базе другой человек или другая
  дисциплина — ошибка: скорее всего, перепутан файл или номер.
- Этапы нужно сначала создать в админке (раздел «Этапы»).
- Утверждённый протокол файлом не меняется — только «Исправлением после утверждения»
  с основанием и подписью утвердившего.
- «Место» — судейское место в дисциплине после последнего пройденного этапа.
  Если его нет, место считается по сумме времени.
