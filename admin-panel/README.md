# Admin Panel

Веб-интерфейс для организаторов и контент-менеджера. Отдельное приложение (не VK Mini App,
обычный веб), использует тот же backend API.

Контент-менеджер должен уметь самостоятельно, без разработчика, обновлять расписание, новости,
карточки участников, статусы участников и результаты (требование из брифа).

## Разделы (см. подробности в docs/screens.md)

Участники · Гонка (этапы, КП, ручной ввод отметок) · Результаты · Контент · Push-рассылки ·
Статус гонки · Статистика болельщиков · Мониторинг оборудования (единственное место, где виден SOS).

## Старт проекта

Исходников и сборки пока нет; стек не выбран (может быть тот же React + TS, что и frontend, но это
отдельное приложение со своей авторизацией для организаторов — не через VK ID).
