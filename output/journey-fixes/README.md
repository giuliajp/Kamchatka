## Воспроизведение

```sh
npm ci --prefix frontend
npm ci --prefix admin-panel
npm --prefix frontend run check
npm --prefix admin-panel run check
cd frontend
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e
```

Backend запускается с настроенной отдельной тестовой БД командой `python -m pytest -c backend/pytest.ini backend/tests -q` из корня. На macOS необходима поддерживаемая UTF-8 локаль: `LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8`; в Linux CI используется `C.UTF-8`. Схемы тестов изолируются и удаляются штатной pytest-фикстурой. Новые миграции не добавлялись.

Для повторной проверки исходного заполненного аудит-набора: `AUDIT_CREDENTIALS=/path/to/local-credentials.json node scripts/verify-journey-fixes.cjs`. JSON содержит `login` и `password` и не коммитится. По умолчанию miniapp/admin доступны на 5198/5199; адреса меняются через `AUDIT_FRONT` и `AUDIT_ADMIN`. API8016 использует прежнюю audit-БД; фоновые опросы трекеров и отправка напоминаний выключены. Скрипт входит через UI и перечитывает существующие данные, не создаёт бизнес-сущности.
