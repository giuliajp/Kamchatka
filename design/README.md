# Design

## Брендбук

`brandbook/kamchatka-brandbook.pdf` — официальный брендбук проекта (тот самый, что указан по
ссылке в брифе заказчика). Логотип «КАМЧАТКА», основные и дополнительные цвета, шрифт Gotham Pro,
охранное поле логотипа, допустимые/недопустимые вариации, паттерны, примеры носителей стиля.

Брендбук служит ориентиром для будущей брендизации. По решению пользователя
первый UI-kit использует стандартную тему VKUI до утверждения цифровых стилей.

Цвета и шрифты из брендбука уже переложены в текст (`../docs/brand/colors.md`,
`../docs/brand/typography.md`) и в код (`../docs/brand/theme.reference.ts`, справочный архив без подключения к UI-kit) — открывать сам PDF
на каждый чих не обязательно, но полезно свериться с логотипом и допустимыми/недопустимыми
вариациями его использования (стр. "ДОПУСТИМЫЕ / НЕДОПУСТИМЫЕ ВАРИАЦИИ").

## Что ещё должно тут появиться

- Рабочая ссылка Figma записана в `figma-link.md`; доступ и готовность макетов требуют проверки.
- Экспортированные ассеты бренда (логотип в SVG, иконки, паттерны) — в `brand-assets/`.
- Макеты всех экранов, светлая и тёмная темы, набор иконок и иллюстраций, интерактивный
  прототип ключевых сценариев (требования из брифа) — ведутся в Figma, сюда попадают только
  экспорты (SVG/PNG), а не сам процесс дизайна.

## Референсы для дизайна (из брифа)

- Iditarod Insider / Iditarod GPS Tracker — подача live-трекинга.
- Trackleaders.com — трекинг ультрамарафонов.
- Yukon Quest — карточки участников и результаты.
- Стиль: минимализм, outdoor-эстетика, крупная карта, воздух, спокойная типографика,
  акцент на фотографиях гонки.

Цвета и шрифты — см. `../docs/brand/colors.md` и `../docs/brand/typography.md`.

> 💡 PDF брендбука весит ~11 МБ. Если в репозиторий добавится ещё несколько похожих файлов
> (презентации, другие тяжёлые PDF), стоит подключить [Git LFS](https://git-lfs.com/) для
> больших бинарных файлов — иначе история репозитория будет разрастаться. Для одного файла это
> не критично, можно коммитить как есть.
