# Шрифты

Получены 1 ноября 2026 по запросу пользователя; desktop TTF установлены в
`~/Library/Fonts`, web WOFF2 сохранены в этом каталоге. Внешний CDN приложению не нужен.

| Семейство | Начертания | Полученный источник |
|---|---|---|
| Gotham Pro | Regular, Medium, Bold, Black | npm `gotham-pro-font@1.0.0`, https://registry.npmjs.org/gotham-pro-font/-/gotham-pro-font-1.0.0.tgz |
| VK Sans Display | Regular, Medium, DemiBold, Bold | https://github.com/Eugene-max/VK-Sans-Display-font |

WOFF2 преобразованы из исходных шрифтов fontTools/Brotli без замены контуров.
Внутренние имена семейств и начертаний проверены; таблицы cmap содержат А–я, Ё и ё.

Наличие файлов в открытом репозитории или реестре не подтверждает полномочия
их распространителя. Метаданные npm-пакета указывают ISC, но отдельного документа
с правами на сами контуры в архиве нет. Web-права от правообладателя для этих
копий не подтверждены. Покупка не выполнялась; desktop-установка не даёт web-лицензию.
Для публичного выпуска владелец проекта должен подтвердить права либо предоставить
лицензированные оригиналы. Справочный каталог пользователя:
