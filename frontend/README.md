# Фронтенд Авачи

React, TypeScript, VKUI и Leaflet. Карта, участники и результаты используют существующий
FastAPI; отсутствующие функции дополнены явно помеченными локальными демонстрационными данными.

## Запуск

Node.js 22.21+ и npm 10+. Из `frontend`:

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Приложение: http://127.0.0.1:5173. Backend: http://127.0.0.1:8000.
Подготовка PostgreSQL и Python описана в `../backend/README.md`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VITE_API_BASE_URL` | `/api` | Префикс публичного API |
| `VITE_DEV_API_TARGET` | `http://127.0.0.1:8000` | Proxy Vite на backend |
| `VITE_MAP_TILE_URL` | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | Подложка Leaflet |
| `VITE_MAP_ATTRIBUTION` | © OpenStreetMap contributors | Атрибуция поставщика |
| `VITE_MOCK_MISSING_FEATURES` | `false` | Демонстрационные дополнения включаются только явным `true` |

После изменения `VITE_*` перезапустите Vite или пересоберите приложение. Эти настройки
публичны; ключи Iridium и PostgreSQL остаются в `backend/.env`.
Для публикации нужны HTTPS и proxy `/api` либо адрес backend с разрешённым CORS origin.

## Подложка карты

Используется OpenStreetMap через Leaflet. API-ключ не нужен. Подложку и её
копирайт можно заменить переменными `VITE_MAP_TILE_URL` и `VITE_MAP_ATTRIBUTION`.
Служебная подпись Leaflet отключена через штатный `setPrefix(false)`;
копирайт поставщика карты остаётся видимым. Лицензия библиотеки включена в
`public/licenses/Leaflet.txt` и сборку.
Ошибка тайлов видна до начала следующей загрузки, даже если Leaflet завершил
предыдущую загрузку с ошибками. Настоящие маршрут, КП и позиции сохраняются.

## Источники данных

API-контракты остаются в `src/types/api.ts`. Backend и миграции не изменены.

- `/races/current` или `/races/{id}`: гонка, этапы, дисциплины.
- `/stages/{id}`: настоящий маршрут GeoJSON, КП, расстояние и описание.
- `/races/{id}/positions?stage=N&discipline=...`: подтверждённые GPS-точки;
  опубликованные дисциплины скрываются с карты независимо друг от друга.
- `/participants/{id}`, `/races/{id}/participants`, `/races/{id}/results`,
  `/stages/{id}/protocols` и `/race-participants/{id}/track`: настоящие списки,
  биографии, официальные места, времена, штрафы и треки.

Гонка, карта и протоколы обновляются каждые 120 секунд. Списки и карточки — при
открытии, возврате на вкладку и восстановлении сети.
Старые запросы отменяются. Кэш API разделён по URL; треки хранятся только в памяти.
Ошибки и пустые ответы API не заменяются демонстрационными ответами. Недоступные
тайлы не удаляют маршрут и точки. Непрерывное движение участников не имитируется.
GPS-рейтинг, отставание в километрах и свежесть точки отделены от официальных мест,
временного отставания и состояния сети. Время гонки — Камчатка, UTC+12.

Таблица результатов показывает регион и число собак на старте и финише каждого
этапа из API. Отсутствующие значения обозначены `—`, нулевое число собак сохранено.

Локальные дополнения из `src/mocks/extras.tsx` выключены по умолчанию.
Для демонстрации задайте `VITE_MOCK_MISSING_FEATURES=true`:

- Поддержка, подписки и показ предложения уведомлений: `avacha-extras-v1` в
  localStorage, ключ участия `raceId:raceParticipantId`. Общий React-контекст
  синхронизирует карточку, список, маркеры и «Мои»; событие storage — другие вкладки.
  При запрете storage текущая сессия продолжает работать в памяти.
- Счётчик воспроизводим: фиксированная база по ID плюс один при поддержке.
  Отмена поддержки убирает ровно один голос. Подписка включается независимо.
- История прохождения опирается только на существующие КП этапа, даты старта
  и статус. Без КП история отсутствует. Это демонстрация, а не данные трекеров.
- Демонстрационный момент финиша возможен только при завершённом результате
  этапа с опубликованной длительностью и известным стартом; официальное время
  при этом не меняется.
- Доставка push пока не подключена. Все эти дополнения подписаны демонстрационными.

Компонент `StageMedia` с демонстрационными ассетами сохранён для будущего раздела
«Новости и трансляции». На карте фото, видео и отчёт не показываются независимо от флага моков.

Пять пунктов меню видимы. «Программа» и «Ещё» показывают сообщение о готовности раздела.
Будущий этап показывает отсчёт без автоматической имитации старта; отменённый — отмену.
Завершённый — результаты и маршрут из API при его наличии.
Ссылка «Поделиться» восстанавливает `race`, `stage` (ID, не номер), `person`, `entry`.
Используется системное меню, затем буфер обмена и, при отказе, доступная для копирования ссылка.

Архив 2026 содержит результаты 21 участника и 6 этапов, но не маршруты, GPS,
фото и точные старты. Эти поля остаются пустыми при работе с настоящим архивом.

## Дизайн и проверка

Эталон: [Для разработки](https://www.figma.com/design/dZcOxRfG88AY1tWW1s7HKH/?node-id=339-7522),
приоритетная карточка `462:10977`, легенда `462:10123`. Подробности — `../DESIGN.md`.
Gotham Pro и VK Sans Display подключены через локальные `@font-face`; источники
и статус лицензирования — `public/fonts/SOURCES.md`. Установка desktop-шрифтов
не заменяет web-файлы в сборке.

```bash
npm run check
npm run storybook
```

`check`: ESLint, TypeScript, тесты с неизменными порогами 100% каждого рабочего
TS/TSX-файла, production и Storybook. Исходные 134 теста сохранены; новые проверки
дополняют их. Storybook — http://127.0.0.1:6006; только тесты и Storybook импортируют
HTTP-фикстуры. Production не содержит подмены основных API.

## Ревью и CI

Итоговое [ревью от 1 ноября 2026](../docs/frontend-review.md): 184 теста,
100% каждого рабочего файла, обе сборки и полный npm audit без уязвимостей.
GitHub Actions повторяет npm ci, check и аудит для frontend PR.
Overrides glob/minimatch закрывают уязвимости инструментов разработки; новые
production-зависимости для ревью не добавлялись.
