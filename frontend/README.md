# Мини-приложение «Авача»

React, TypeScript, VKUI, официальный VK Bridge и Leaflet. Пять вкладок: карта,
участники, результаты, программа и «Ещё». Рабочее приложение использует backend API;
фикстуры остаются только в тестах и Storybook.

Описание API: [docs/api.md](../docs/api.md).

## Запуск

Node.js 22.21+ и npm 10+, из `frontend`:

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Приложение: http://127.0.0.1:5173. Подготовка PostgreSQL/Python —
[backend/README.md](../backend/README.md).

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VITE_API_BASE_URL` | `/api` | Префикс backend API |
| `VITE_DEV_API_TARGET` | `http://127.0.0.1:8000` | Proxy Vite |
| `VITE_MAP_TILE_URL` | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | Подложка карты |
| `VITE_MAP_ATTRIBUTION` | © OpenStreetMap contributors | Атрибуция поставщика |

После изменения настроек перезапустите Vite/сборку. Значения `VITE_*` публичны:
секреты VK и Iridium остаются на backend. Для публикации нужны HTTPS, зарегистрированный
VK Mini App и proxy `/api` либо разрешённый CORS origin. Развёртывание в этой поставке не выполнялось.

## Данные и VK

- Все запросы приложения получают исходный `window.location.search` в
  `X-VK-Launch-Params`. Параметры не сортируются и не пересобираются.
- Bridge выполняет инициализацию, получает оформление, открывает диалоги уведомлений
  и шеринга. При запуске вызывается `POST /me/visit`; подтверждённое изменение
  разрешения сохраняется через `PUT /me/notifications`. Отказ и закрытие диалога
  не считаются согласием. Вне VK доступны публичные разделы; личные действия требуют VK.
- «Болею за», отмена, «Мои», рейтинг, прирост, счётчики и уведомления участника
  используют серверные данные. Повторная запись блокируется до завершения запроса;
  после успеха обновляются связанные списки. Старые демонстрационные подписки не переносятся.
- Судейские прибытия/отправления берутся из `checkpoint-passes`. GPS и официальный
  результат разделены; персональный финиш появляется только при отметке финишного КП.
- Программа и зрительские локации зависят от выбранного сезона. «Ещё» содержит
  маршрут/высоты, FAQ, контакты, профиль, сохранённые материалы, новости и фото.
- `503` новостей/фото скрывает только недоступную секцию; `stale: true` показывает
  отметку о свежести. Анонс ведёт к оригинальной записи VK. Медиа на карте отсутствуют.
- Все календарные даты отображаются в `Asia/Kamchatka`. Протокольное время остаётся
  длительностью: `27:02:02` не превращается в время суток. В протоколе сохранены регион
  и собаки на старте/финише; отсутствующие значения не выдумываются.

Публичный offline-кэш разделён по URL. Личные ответы `/me` и `/support` не сохраняются
на диск; состояние принадлежит текущему пользователю и сбрасывается при его смене.
Старые запросы отменяются, неверные ответы и ошибки не подменяются фикстурами.
Карта и протоколы обновляются каждые 120 секунд; потеря сети и просроченная GPS-точка
показываются отдельно. Отсутствующие тайлы не удаляют маршрут и участников.

Календарь, категории, события, локации, альбомы, профиль и трек сохраняются во fragment URL.
Примеры: `#race=10&section=program&day=2027-02-05&event=1`,
`#race=10&section=results&view=track&stage=103&person=501&participant=9001`.
Серверные напоминания, ETA, PDF и три настройки push используют API миграций 0008–0010.

Push/share-ссылки также используют fragment: `#map&stage=103`, `#participant=14`,
`#results`. Сохранена совместимость с прежними `race`, `stage`, `person`, `entry`.
Подписанные параметры VK не изменяются и не попадают в распространяемую ссылку.
Ссылка на участника без сезона разрешается через список сезонов, включая архив.

## Истории VK

Действие «В историю VK» доступно у участника, на экране результатов/трека и у новости,
если приложение открыто внутри VK и клиент поддерживает `VKWebAppShowStoryBox`.
Участник и результаты требуют корректного `vk_app_id`: localhost и preview в историю
не попадают. Прежние отправка ссылки и репост новости остаются отдельными действиями.

По нажатию Canvas готовит PNG 1080 × 1920 и отдельный кликабельный стикер перехода.
Используются локальные фон, логотип и шрифты; внешние фото не загружаются, изображения
не сохраняются на сервере. Декоративный фон/логотип и шрифт имеют резервный вариант.
В результатах указаны официальное место в дисциплине и время **за гонку**, без подмены
GPS-данными; отсутствующие значения показаны как «—». Launch-параметры и `sign` в
ссылку не включаются.

Подготовка ограничена 10 секундами, ожидание редактора — 60 секундами. Отмена не
показывает успех и не запускает репост автоматически. Если VK не ответил, нужно
проверить свою историю перед повтором. Подтверждение Bridge не означает проверенную
публикацию: её пользователь завершает в редакторе VK. Расположением истории в ленте
управляет VK.

Перед выпуском проверить зарегистрированное HTTPS-приложение на Android, iOS и
в desktop web VK: три карточки, отмену и повтор, возврат в приложение, публикацию
пользователем и переход по стикеру к нужному участнику, результатам или новости.
Реальная приёмка VK пока не выполнена; эмуляция транспорта в Playwright её не заменяет.
Браузерный отчёт содержит примеры PNG, длинное имя, отсутствующие результаты и fallback.

Неиспользуемый `StageMedia` и его демонстрационная галерея удалены. Старые ссылки на
галерею открывают завершённый этап с маршрутом и результатами. В `public/figma` осталось
33 используемых файла (3 308 492 байта вместо 19 405 391); удалены 18 экспортов на
16 096 899 байт. `b5483.png`, `5b9db.svg`, маркеры и ассеты действующего Storybook сохранены.

## Дизайн и проверки

Пользовательский UI kit, Gotham Pro и VK Sans Display сохранены из PR #4.
Источники шрифтов: [public/fonts/SOURCES.md](public/fonts/SOURCES.md).
Подложка Leaflet сохраняет атрибуцию поставщика; лицензия включена в `public/licenses`.

```bash
npm run check
npm audit --audit-level=moderate
npm run storybook
```

Storybook по умолчанию: http://127.0.0.1:6006. `check` выполняет lint, TypeScript,
тесты с порогами **100% каждого рабочего TS/TSX-файла**, production и Storybook.
CI проверяет оба приложения и backend. Проверка связки с реальным backend —
`scripts/verify-ui-api.py`.

Production-проверки браузера запускаются из `frontend`:

```bash
npx playwright install chromium
npm run test:e2e
```

Playwright сам собирает оба приложения и поднимает preview на 5185/5186 и статический Storybook на 5187 (нужен Python 3).
Записи API изолированы фикстурами, Leaflet настоящий. Матрица включает обе темы,
текст 200%, короткий экран и axe; цвета Figma сохранены по решению пользователя,
поэтому нарушения контраста сохраняются в отчёте как принятое исключение.
HTML-отчёт — `playwright-report`, trace и снимки падений — `test-results`.
