# Frontend — VK Mini App

React + TypeScript, VKUI, VK Bridge, VK ID. SPA, адаптив под мобильные устройства, планшеты и веб-версию ВК.

## Структура

```
src/
├── screens/        # один экран приложения = одна папка (см. docs/screens.md)
├── components/      # переиспользуемые UI-компоненты
├── styles/           # theme.ts — цвета и шрифты из брендбука, светлая/тёмная темы
├── api/               # запросы к backend
├── hooks/            # кастомные React-хуки
├── store/             # состояние приложения (список "болею за", тема и т.д.)
├── types/             # общие TypeScript-типы
└── assets/
    ├── icons/
    ├── images/
    └── fonts/         # файлы шрифта Gotham Pro (или временная замена — см. docs/brand/typography.md)
```

## Старт проекта (когда стек будет выбран окончательно)

Это заготовка структуры, а не готовый проект. Кто-то из команды должен инициализировать сборку, например:

```bash
npm create vite@latest . -- --template react-ts
npm install @vkontakte/vkui @vkontakte/vk-bridge @vkontakte/icons
```

После инициализации — перенести файлы из `src/` (они уже разложены по папкам) в структуру,
которую создаст Vite, и запустить:

```bash
npm run dev
```

## Важно из брифа

- Карта — главный экран (`screens/Map`).
- Положение участника — последняя подтверждённая точка с подписью времени, не "живое" движение.
- Приложение должно нормально работать офлайн: показывать последние загруженные данные и баннер
  «Нет соединения».
- Высокий контраст, крупные элементы — читаемость на морозе и солнце.
